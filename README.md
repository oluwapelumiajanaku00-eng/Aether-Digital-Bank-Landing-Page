# Aether Landing Page

Aether is a modern, responsive landing page built to showcase a polished product-style web experience with a strong visual hierarchy and responsive layout.

## Overview

This project focuses on clean frontend implementation, responsive behavior, accessible HTML structure, and a consistent visual system.

### Highlights

- Responsive layout across desktop, tablet, and mobile screen sizes
- Modern, product-focused visual design
- Semantic HTML structure
- Reusable and maintainable CSS
- Clean project structure suitable for a portfolio
- Fast-loading, lightweight frontend

## Tech Stack

CSS, HTML, JavaScript

## Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd aether-landing-page
```

### 2. Run the project

Open the project locally with your preferred local development server.

For a static project, serve the folder with a local web server (for example VS Code Live Server).
